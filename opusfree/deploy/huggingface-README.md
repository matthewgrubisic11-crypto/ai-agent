# opusfree

A free, fully-local Opus Clip alternative — turn one long video into scored,
captioned, vertical short clips. Running here as a Docker Space.

> Tip: set this Space to **Private** (Settings → Change visibility) so only you
> can use it — otherwise anyone with the URL can run jobs on your free compute.
